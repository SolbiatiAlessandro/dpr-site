# dpr.info — design concepts

Two website concepts for Dzogchen Ponlop Rinpoche, both following the page structure of
[kagyuoffice.org](https://kagyuoffice.org/). Static HTML, generated from the private working
repo `dpr-website` (content, analysis and build script live there).

- Concept A · Classic (older audience): `classic/`
- Concept B · Rebel (younger audience): `younger/`

Work in progress, September 2026. Not the live site. Photos and text are from dpr.info and
Rinpoche's official channels.
